# Random Password Generator

**Автор:** Алексей Молоков

**Язык:** Russian

## Описание

GUI-приложение для генерации случайных паролей с возможностью настройки параметров. Приложение позволяет:
- Выбирать длину пароля (от 4 до 50 символов)
- Включать/исключать цифры, строчные и заглавные буквы, спецсимволы
- Сохранять историю сгенерированных паролей в JSON-файл
- Копировать пароль в буфер обмена одним кликом

## Требования

- Python 3.6 или выше
- tkinter (обычно входит в стандартную установку Python)
Использование

    Использование:
    Настройте параметры пароля:

        Используйте ползунок для выбора длины

        Отметьте нужные типы символов

    Нажмите "Сгенерировать пароль"

    Пароль появится в поле ввода

    Нажмите "Копировать" для копирования в буфер обмена

Функциональность

    Валидация: проверка выбора хотя бы одного типа символов

    История: сохранение в JSON и загрузка при следующем запуске

    Безопасность: использование криптографически безопасного random.choice

Примеры тестирования
Тест 1: Генерация стандартного пароля

    Длина: 12

    Все чекбоксы отмечены

    Нажать "Сгенерировать"
    Ожидаемый результат: пароль длиной 12 символов

Тест 2: Проверка валидации

    Снять все чекбоксы

    Нажать "Сгенерировать"
    Ожидаемый результат: сообщение об ошибке

Тест 3: Проверка истории

    Сгенерировать несколько паролей

    Закрыть и открыть приложение
    Ожидаемый результат: история сохранена
